## 解决每次开机电脑时间日期格式恢复默认

### 问题描述

每次关机前调整格式为24小时、年/月/日。但是开机后不到一分钟会变成12小时制和日/月/年

### 原因

系统格式被设置成了**简体中文(新加坡)**，不清楚原因，也许是系统更新或者	同步导致

### 解决

`win+R`，输入`intl.cpl`，发现系统格式被设置成了**简体中文(新加坡)**，在新加坡的区域标准中，默认的短日期恰好就是 `d/M/yyyy`（日/月/年），默认时间也是 12 小时制。

点击 **格式(F)** 下方的下拉菜单，选择 **中文(简体，中国)**。

点击右下角的 **应用(A)**。

接着切换到上方的 **管理** 选项卡，点击 **复制设置** 按钮。

在弹出的窗口最下方，**勾选**以下两项：

- **欢迎屏幕和系统账户**
- **新建用户账户**

点击 **确定** 保存所有设置。

## 输入法默认语言修改

### 问题描述

我装了日语输入法，但是，每次开机默认就是日语，还需要shift+alt转英文，太麻烦，怎么办？能不能默认英文？还有，我之前在设置里关了日语（我不记得怎么操作的了，但那之后就默认英文没有日文输入法）。但是现在不知道是windows的问题还是什么，又开始出现日语且默认日语，怎么回事？

### 原因

大概是**Windows 系统更新**重置了部分语言设置，或者是**账号同步**功能把之前的语言偏好又同步回了这台电脑。

### 解决

设置--> 时间和语言--> 输入--> 高级键盘设置--> 替代默认输入法

 **替代默认输入法** 下拉菜单中，不要选“使用语言列表(推荐)”，而是**直接手动选择中文或英文输入法**（“简体中文(中国大陆) - 微软拼音”）。

关于输入法的详细内容，见：[windows上的语言和输入法](language-and-input-on-windows.md)，以及gemini对话：[gemini-解决Windows默认日语输入法](https://gemini.google.com/app/a2946a6651f37256)

```

C:\Users\<YourUsername>>
```

查看该文件的Installed batteries部分，如下：

```

CHEMISTRY	LION
```

## 找回忘记的 Wi-Fi 密码

有时候家里或公司的 Wi-Fi 连久了，自己反而忘了密码是多少。Windows 把所有连过的 Wi-Fi 密码都记在底层了，可以用命令直接翻出来。

先输入这个命令，查看你电脑连接过的所有 Wi-Fi 名称：

```
netsh wlan show profiles
```

找到想查的 Wi-Fi 名称后，输入下面这个命令（把 `WiFi名称` 替换成实际看到的名字）：

```
netsh wlan show profile name="WiFi名称" key=clear
```

运行后，在弹出的信息中找到“安全设置”下的**“关键内容”**，后面的字符就是这个 Wi-Fi 的密码。

## powertoys，powertoys awake，windows命令面板

### 1. PowerToys（主程序）

这是整个工具集的核心引擎和管理中枢。

- **它是干嘛的：** 它负责统筹和运行你在设置中开启的所有其他实用工具，比如 FancyZones（窗口分屏）、Keyboard Manager（按键映射）、Color Picker（屏幕拾色器）等。
- **为什么自启：** 只有主程序在后台运行，你的全局快捷键和系统自定义修改才能生效。双击这个图标可以打开 PowerToys 的主设置界面。

### 2. PowerToys Awake（唤醒工具）

这是一个专门用来管理电脑睡眠状态的独立小工具。

- **它是干嘛的：** 它可以强制电脑保持唤醒状态，防止其自动休眠或关闭屏幕。这在你下载大文件或进行演示时非常有用，省去了去 Windows 控制面板里频繁修改“电源计划”的麻烦。
- **为什么自启：** 它提供一个独立的托盘图标，是为了让你能随时右键点击，极速切换当前的唤醒模式（例如“无限期保持唤醒”、“保持唤醒 2 小时”或“保持屏幕常亮”）。

### 3. Windows 命令面板 (Command Palette)

这是 PowerToys 近期主推的一个全局快捷启动器（类似于 macOS 里的 Spotlight 搜索）。

- **它是干嘛的：** 默认按下 `Win + Alt + 空格` 键，屏幕中央就会弹出一个极简的搜索框。你可以用它瞬间搜索并打开电脑里的软件、查找深层文件、进行数学计算、或者直接运行系统命令，主打响应极快且无广告干扰。
- **为什么自启：** 它拥有独立的后台进程和托盘图标，是为了保证你按下快捷键时它能“秒开”，同时方便你快速访问和管理它支持的各种高级扩展插件。

## 软件清理残留

**AppData 文件夹（最常见）**： 打开文件资源管理器，在地址栏分别输入以下路径并回车，寻找与该软件或开发者同名的文件夹并删除：

```
%APPDATA%
```

```
%LOCALAPPDATA%
```

**文档或用户根目录**： 去 `C:\Users\你的用户名\` 下看看有没有类似 `.软件名`（带个点的隐藏文件夹）或者在 `Documents` 文件夹中。

**注册表（高级）**： 按下 `Win + R`，输入以下命令打开注册表：

```
regedit
```

然后在 `HKEY_CURRENT_USER\Software` 或 `HKEY_LOCAL_MACHINE\SOFTWARE` 下寻找对应的软件名并删除（注意：修改注册表有风险，请务必只删除你确定的项）。



##  Windows “运行” 对话框：Win+R

### 系统配置与管理工具

`intl.cpl` 打开控制面板中的“区域”设置，用于更改系统的日期、时间或数字格式。

`cmd` 打开“命令提示符”（Command Prompt），用于执行基础的系统命令。

`powershell` 打开 Windows PowerShell，这是一个比 cmd 更强大的基于任务的命令行 shell 和脚本语言工具。

`resmon` 打开“资源监视器”（Resource Monitor），可以直观且实时地查看 CPU、内存、磁盘和网络的详细使用情况。

`services.msc` 打开“服务”管理器，用于查看、启动、停止或配置 Windows 系统及第三方软件的后台服务。

`regedit` 打开“注册表编辑器”，用于查看和修改 Windows 系统注册表的高级配置参数。

`cleanmgr` 打开“磁盘清理”工具，用于扫描并删除临时文件、系统更新缓存等，以释放硬盘空间。

`devmgmt.msc` 打开“设备管理器”，用于查看和管理计算机上安装的所有硬件设备状态及驱动程序。

`control` 直接打开经典的 Windows“控制面板”。

### 系统路径与环境变量

带有 `%` 符号的命令是 Windows 的环境变量，用于在不输入完整绝对路径的情况下，快速跳转到当前用户的特定隐藏文件夹：

`%LOCALAPPDATA%\Microsoft\Edge\User Data` 直接打开 Microsoft Edge 浏览器的用户数据存储目录，其中包含你的书签、历史记录、扩展缓存和本地配置。

`%temp%` 打开当前用户的“临时文件夹”。这里存放着各种软件运行或安装时产生的临时文件，通常可以直接清理掉。

`%APPDATA%` 打开当前用户的 `Roaming` （漫游）应用程序数据文件夹。许多软件会将用户配置和存档保存在这里。

`%localappdata%\Programs` 打开当前用户的本地程序安装目录。许多支持“仅为当前用户安装”的软件（如微信、VS Code 等）默认会安装在这个路径下。

### 第三方工具

`scrcpy` 这是一个非常受欢迎的开源安卓手机投屏工具（Screen Copy）的启动命令。电脑已经安装并配置好了它的环境变量，连接安卓手机后运行此命令，就可以将手机屏幕镜像到电脑上并使用键鼠控制。





## 要删除以前版本的windows吗？

系统弹窗提示

这是 Windows 系统的常规提示。当你的电脑刚刚经历过一次重大的系统更新（比如升级到 Windows 11 或安装了年度大更新），并且碰巧你的 C 盘存储空间快满时，系统就会弹出这个窗口。

这取决于你当前电脑的运行状态：

- **建议点击“删除”：** 如果你的电脑更新后已经平稳运行了几天，没有出现卡顿、蓝屏、软件不兼容或文件丢失的情况，而且你确实很缺硬盘空间。删除它可以释放出非常可观的空间（通常在 10GB 到 30GB 之间）。
- **建议暂缓，点击“消除”：** 如果你的电脑是刚刚才更新完，或者更新后你觉得系统有些小 Bug、用起来很不顺手，你可能还会用到“回退到上一版本”的功能。此时请保留它。

## 弹出硬盘失败：查找是什么程序在占用

### 资源监视器

win+R：

```
resmon
```

在弹出的窗口中，点击顶部的 **“CPU”** 选项卡。

找到中间的 **“关联的句柄” (Associated Handles)** 搜索栏（如果没有展开，点击右侧的箭头展开）。

在搜索框中输入你的移动硬盘盘符（例如你的硬盘是 E 盘，就输入 `E:` ）。

**查看结果：** 下方的列表会显示出所有正在占用该盘符的进程。

- **解决：** 右键点击该进程，选择 **“结束进程”**，然后再尝试弹出硬盘。

### 事件查看器

右键点击“开始”菜单图标，搜索**“事件查看器”**。

在左侧菜单栏，依次展开：**Windows 日志** -> **系统**。

在右侧的操作栏中，点击 **“筛选当前日志...”**。

在“所有事件 ID”那一栏输入 `225`，然后确定。

- *注：事件 ID 225 代表“应用程序 X 阻止了移除设备”。*

**查看结果：** 点击筛选出的日志，下方的“常规”描述里会明确写出是哪个进程（Process Name）阻止了弹出。

### 重启资源管理器

很多时候，占用硬盘的其实是 Windows 自己的文件浏览窗口（即使你已经关闭了所有窗口，后台可能还在刷新缩略图）。

### 其他可能

**清空剪贴板：** 如果刚才从移动硬盘“复制”了一个文件，但还没有“粘贴”，剪贴板会占用硬盘。随便在桌面上复制一个文本文件，覆盖掉剪贴板即可。

**清空回收站：** 如果在移动硬盘上删除了文件，文件可能还在回收站里（移动硬盘也是有回收站机制的），尝试清空回收站。

**杀毒软件/Windows Defender：** 它们可能正在扫描新插入驱动器中的文件。
